# Sanitization Record

## Removed from public material

- Employer and customer names
- Employee and support-group names
- Email addresses, phone numbers, usernames, and account identifiers
- Passwords, default credentials, MFA enrollment details, and recovery procedures
- Ticket numbers, ticket URLs, internal KB links, and internal application URLs
- Production IP addresses, hostnames, site numbers, device labels, and cable-port maps
- Private screenshots and original document metadata
- Product-specific departmental routing and service-level targets

## Rewritten

- Printer procedures were corrected so WSD is not described as USB and destructive steps require approval.
- VPN percentage indicators were removed as a universal diagnostic model.
- Ticket priority is based on impact and urgency, not requester title.
- Camera troubleshooting now separates recorder, camera, network, power, and viewing-client layers.
- The network case study uses generalized device roles and no production identifiers.

## Excluded source documents

The public repository does not include the original DOCX files. Source material that contained credentials, MFA procedures, employee provisioning, internal URLs, or unsafe registry/profile changes was not converted into a public guide.
